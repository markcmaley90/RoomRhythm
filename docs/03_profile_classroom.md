# 03 — Classroom Profile (school)

## Purpose
Everyday focus blocks and room rhythm for teachers/students.

## BUILT
- Focus Duration timer (slider min 0m), auto-break toggle, Calm/Focus/Break/Recharge cycle.
- Sound engine + Sound Picker, 1-min warning, 3-2-1 beeps.
- CalmCountdown wash into focus timer.
- Projector mode, fullscreen, tab snap-back, ScreenFlash, EmergencyButton.
- Keyboard up/down timer adjustment with hints.

## NEXT (paid-tier hooks)
- Save a teacher's preferred room setup (requires auth + backend) — mirror the proven Classroomscreen paid hook: free forever, but **saving your setup** is Pro.
- Multi-device: teacher controls, students view-only (see `07_multidevice_sync.md`).

## LATER
- Noise meter (engagement signal).
- Custom break prompts / teacher customization layers.
- Community templates (shareable session configs).

## Rules reminder
- "Focus Duration" only, never "Pomodoro / Focus Duration". Slider floor stays 0m.
